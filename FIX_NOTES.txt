StreamLive WebApp 1.2.0 — исправления текущей сборки

Изменения:
- Авторизация, регистрация и проверка текущей сессии выполняются на origin,
  с которого открыта WebApp. Это предотвращает случайную регистрацию на другом
  зеркале из-за сохранённого sl_base и несовпадение домена PHP-cookie.
- Переключение зеркала для остальных API-запросов сохранено.
- Режим разработчика теперь можно открыть семью нажатиями по номеру сборки
  в Настройки → О приложении.
- verify.php проверяет фактический путь WebApp API: /webapp/api/native_auth.php.
- README синхронизирован с версией 1.2.0.

Проверки:
- app.js: node --check — OK.
- games.js: node --check — OK.
- webapp/index.php, webapp/verify.php, webapp/api/native_auth.php: php -l — OK.

Важно:
- Это исправление WebApp-клиента, основной PHP-сайт и его .htaccess не изменялись.
- ERR_TOO_MANY_REDIRECTS формируется серверными HTTP-перенаправлениями. Для
  окончательного исправления серверной петли нужен текущий .htaccess/конфиг
  именно с domtv.blyz.ru и цепочка Location из Network; исходный архив сайта
  не доказывает, что на сервере сейчас лежит та же конфигурация.
- Глобальное скрытие профиля и ежедневные награды нельзя честно реализовать
  только локальным интерфейсом: нужны серверные API и хранение состояния.
  Эти функции здесь не имитируются и не выдаются за работающие.
